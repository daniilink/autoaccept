# DotaAccept

Небольшая программа для Dota 2 на Windows (AutoHotkey v2), которая

- **принимает окно «матч найден»** и **приглашения в пати**;
- по желанию **выбирает героя** из твоего списка приоритетов в первом раунде пика;
- по желанию **присылает уведомления на телефон** (через [ntfy](https://ntfy.sh)): матч найден и принят или принять не вышло;
- живёт в трее с **окном настроек** (галочки, список героев), редактировать файлы не нужно.

Работает в фоне, не перехватывает мышь и не трогает память игры.

## Как это работает

Dota 2, запущенная с параметром `-condebug`, пишет обычный текстовый `console.log`. Скрипт читает его и реагирует на то, что сообщает сама игра (матч найден, приглашение в пати, началась стадия выбора героев). Кнопки он ищет по пикселям окна Dota, а нажатие сначала **отправляется прямо в окно игры, курсор не двигается**; только если игра не подтвердила, делается настоящий клик, и курсор возвращается на место. Каждое действие пишется в `dota_log.txt` (интерфейс и лог скрипта на английском).

Язык клиента не важен: скрипт читает внутренние названия сообщений и узнаёт экраны по иконкам, а имена героев в русском и украинском клиенте тоже английские.

## Установка

1. Установи **[AutoHotkey v2](https://www.autohotkey.com/)** (64-разрядный Windows).
2. Скачай в одну папку (не в Program Files): `DotaAccept.ahk`, `heroes_map.txt`, `myheroes_tpl.txt`.
3. В Steam: правый клик по **Dota 2 → Свойства → Параметры запуска** и впиши

   ```
   -condebug
   ```

   (остальные параметры оставь, например `-novid -condebug`). Перезапусти Dota 2.
4. Дважды кликни `DotaAccept.ahk`. Пока дота закрыта, он ждёт, при запуске доты встаёт на взвод. При первом запуске скрипт добавляет себя в автозагрузку Windows (выключается в настройках).

Если параметра запуска нет, скрипт покажет **одно тихое уведомление Windows** с подсказкой (не больше трёх раз), а значок в трее сменится на «паузу».

## Окно настроек

Правый клик по значку в трее → **«Settings…»** (или двойной клик).

- **Основное:** автопринятие матчей и приглашений, уведомления на телефон (скопировать тему, тест), запуск с Windows, открыть лог.
- **Автопик героев:** включение, задержка и **список героев**: отмечай галочками, порядок задаётся кнопками ▲ ▼. `Ctrl+Alt+P` — пауза всего.

Значок в трее — это значок самой Dota, когда всё в порядке, и встроенный «II» AutoHotkey, когда пауза или что-то не так (наведи курсор, чтобы прочитать причину: нет параметра запуска, лог доты молчит 5+ минут и т. д.).

## Автопик героя (по умолчанию выключен)

Когда начинается стадия выбора героев, скрипт ждёт (по умолчанию 15 с, чтобы осталось время на таймере), потом читает экран и выбирает **первого героя из списка, который не в бане и не взят**. Он нажимает карточку, затем LOCK IN, и проверяет результат по экрану:

- если клик по карточке не выбрал героя (серая/занята), берёт следующего;
- если герой выбран, а LOCK IN остаётся тусклым (кто-то из команды уже выбрал, второй раунд ещё не начался), **ждёт, пока кнопка засветится**, и фиксирует того же героя;
- если пока ждёт, карточка героя стала серой или забанена, берёт следующего;
- новые попытки он начинает только примерно до 24-й секунды стадии (таймер первого раунда 0:25); `deadline_ms` в `dota_accept.ini` меняет это;
- если за компом кто-то есть (мышь или клавиатура двигались последние 6 с), он ждёт и не мешает.

Поддерживаются два экрана, они определяются сами: **стандартная сетка** (сортировка *Attributes*) использует твой список; **полоса «MY HEROES»** (сортировка *Custom Layout*, только английский клиент) берёт полосу слева направо. Положение героев считается по `heroes_map.txt`, который `tools/build_hero_map.py` строит из файлов самой Dota (только чтение; запусти заново после патча с новыми героями; нужен Python).

## Уведомления на телефон (необязательно)

Поставь приложение ntfy и подпишись на свою тему (Settings → «Copy ntfy topic»). Максимум два сообщения на матч: **«Матч найден и принят»** и **«Матч найден, autoaccept не сработал — прими игру!»** (за 5 секунд ничего не принято). Тема создаётся случайной при первом запуске и лежит в `dota_accept.ini`; относись к ней как к паролю. У публичного сервера ntfy.sh есть суточный лимит сообщений, поэтому их так мало.

## Ограничения — прочитай

- Писалось на **2560×1440** и проверено ещё на одном ноутбуке (стандартная сетка героев, матчи с ботами). Положения хранятся в долях окна. **Автопик поддерживает только окна 16:9**; другие пропорции он отклоняет (см. лог).
- Кнопки скрипт находит по пикселям экрана, поэтому **не видит окно, пока Dota закрыта другим окном**; если экран читается чёрным, выбери «Окно без рамки» вместо полноэкранного режима.
- Живьём пока не проверено: как выглядит серая карточка героя, которого взяла другая команда (скрипт ещё проверяет выбор по реакции самой игры), кнопка приглашения в пати на других разрешениях, полоса «MY HEROES» не на аккаунте автора и запасное принятие по экрану для повторного поиска, когда лог молчит.
- Без `-condebug` скрипт вообще не видит матчи.
- Это любительский проект, писавшийся на одном компьютере; шероховатости возможны.

## Файлы

`DotaAccept.ahk` (скрипт), `heroes_map.txt` (имена героев и порядок в сетке, создаётся из файлов игры), `myheroes_tpl.txt` (шаблон надписи «MY HEROES»), `tools/build_hero_map.py` (пересоздаёт карту). Во время работы рядом создаются: `dota_accept.ini` (настройки, секретная тема), `dota_log.txt`, `snapshots/` (последние 12 кадров экрана пика для отладки).

## Отказ от ответственности

Неофициальный любительский инструмент, не связан с Valve. Он не читает и не меняет память игры и ничего в неё не внедряет: читает текстовый лог, который пишет игра, смотрит на пиксели экрана и шлёт мышиные события в окно игры. **Автоматизация всё равно может нарушать правила сервиса или турнира; позицию Valve этот проект гарантировать не может, а автопик героя (действие внутри игры) чувствительнее, чем принятие матча.** Поэтому автопик по умолчанию выключен. **Используешь на свой риск.**
